# Прогон 1 · 17.10.2026

Правки приложения и движка. Вопросы к содержанию сценария — в
[scenarios/lemonade/backlog.md](../scenarios/lemonade/backlog.md).

Заказчик играет за команду Furrball, вторая команда («Кислые») — бот,
ходит иначе. Лимонад, сессия EPWEL, локально.

## Уже сделано во время прогона (не закоммичено)

- Раскладка вводной `below`: текст сверху, картинка под ним; высота
  картинки ограничена.
- Значки сценария: `currency.short: 🪙`, `icons: {people: 👤, unit: 🥤}` —
  после чисел.
- «Малыш выпил 1 стакан сам» в понедельник: параметр партии `own_use`
  в движке, число — в `params.yard.own_cups_mon`.
- Справка открывается по дням (`from:`): двор, «мама наливает» с Чт,
  парк, кола, флаеры, лимонад в парке.
- Подписи счетов по фазам (`accounts.<счёт>.by_phase`); одинаковые
  подписи — одна строка: во дворе «Платёж маме −30».
- Строка «Дебиторка» в итогах дня.
- Проектор: колонки по всем командам; при нескольких командах — строка на
  команду, на всю ширину; автосжатие шрифта под высоту экрана.
- Белый текст на заливных кнопках; видимые варианты ответа.
- Тема из сценария `theme: light | dark`; лимонад — светлый.
