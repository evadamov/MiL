# Прогон 1 · 17.10.2026

Правки приложения и движка. Вопросы к содержанию сценария — в
[scenarios/lemonade/backlog.md](../scenarios/lemonade/backlog.md).

Заказчик играет за команду Furrball, вторая команда («Кислые») — бот,
ходит иначе. Лимонад, сессия EPWEL, локально.

## Уже сделано во время прогона (не закоммичено)

- Раскладка вводной `below`: текст сверху, картинка под ним; высота
  картинки ограничена.
- Значки сценария: `currency.short: 🪙`, `icons: {people: 👤, unit: 🥤}` —
  после чисел.
- «Малыш выпил 1 стакан сам» в понедельник: параметр партии `own_use`
  в движке, число — в `params.yard.own_cups_mon`.
- Справка открывается по дням (`from:`): двор, «мама наливает» с Чт,
  парк, кола, флаеры, лимонад в парке.
- Подписи счетов по фазам (`accounts.<счёт>.by_phase`); одинаковые
  подписи — одна строка: во дворе «Платёж маме −30».
- Строка «Дебиторка» в итогах дня.
- Проектор: колонки по всем командам; при нескольких командах — строка на
  команду, на всю ширину; автосжатие шрифта под высоту экрана.
- Белый текст на заливных кнопках; видимые варианты ответа.
- Тема из сценария `theme: light | dark`; лимонад — светлый.

## Решено, применить после прогона

1. Управление без пульта: листание на проекторе (пробел, →, кликер; ← назад)
   по ссылке ведущего.
2. Оглавление пройденных слайдов на проекторе (клавиша, стрелки, Enter, Esc).
3. На приёме ходов — вопрос (всегда, даже без задания к ходу) и список
   команд с отметкой «ответили»; счётчик «Отправили N из M» — мельче.
4. Убрать фазу «приём закрыт» и правку ходов ведущим: «дальше» на приёме
   сразу показывает результаты.
5. Не показывать подсказки `### trainer`.
6. Пульт убрать из v1; сначала поправить спеку.
7. Общие тексты на проекторе — без чисел конкретной команды (сейчас берутся
   из эталона: «Продано 30, из них 16 в долг» при 15 у Furrball). Числа —
   только на телефонах команд. Уточнение: число в общем тексте допустимо, только если
   оно одинаково у всех команд (Д5 «Купили 18»); проверка сценария ловит
   подстановки, зависящие от ходов.
8. Таблица итогов: колонку «Продано» по центру; «(в долг 6)» → «(6)».
9. «Деньги на конец» → «Деньги в кассе».
10. «Мои дни» на телефоне: в столбце «Продано» показывать и в долг —
    «15 (6)»; без этого не на что опереться в прогнозе среды.
11. Картинка вводной всегда под текстом — и на проекторе, и на телефоне:
    текст первичен. Раскладка по умолчанию — `below` вместо `side`.
12. Медиана прогнозов считается неверно (30 и 60 → 30, должно быть 45).
13. Таблица прогнозов на проекторе — с колонкой «Факт» рядом с прогнозом.
14. У таблицы показателей без заголовка (Д3 «Вернули / не вернули») —
    заголовок.
15. Экраны после результатов — три вида, все тексты из сценария:
    - **вопрос** (`### discussion`) — «подумайте», идёт **первым**;
    - **пояснение** (`### debrief`) — объяснение механики, идёт после
      вопроса, отдельным экраном по «дальше»;
    - **рефлексия** (`### reflection`, новое) — в конце сезона: «что было,
      что бы сделали иначе».
    Шаг может иметь любые из них; порядок фаз: результаты → вопрос →
    пояснение (→ рефлексия). Сейчас вопрос и вывод — один экран, вопрос
    после вывода. Описать в формате сценария и спеке.
16. Итоги сезона (Д6): отчёты P&L, Cash Flow и баланс сейчас по «эталонной
    команде», которой в зале нет. Решить: отчёты выбранной команды, колонка
    на каждую команду или только на телефонах.
17. Подписи источников денег по фазам, как у счетов: в Cash Flow двора
    «Ингредиенты» должно совпадать с «Платёж маме» в P&L.
18. Не показывать «Проверка баланса» на экранах — техническая строка.
19. Итоги сезона — несколько экранов по «дальше», а не пять блоков на одном
    слайде.
20. Выводы-ловушки — отдельный экран на проекторе; на телефонах участников
    их не дублировать.
21. Текстовые колонки таблиц — по левому краю (сейчас в «Выводах» текст
    прижат вправо).

## Принципы, подтверждённые на прогоне

- Все тексты — вводные, задания, результаты, выводы, рефлексия, вопросы
  залу — только из сценария. Приложение и движок их не сочиняют и не
  подставляют свои; от платформы — только подписи интерфейса и таблиц.

## Оставить как есть

- Кувшин (капвложение 15) не виден отдельной строкой в итогах дня —
  хороший вопрос залу «куда делись деньги».

- Мелькание темы системы при первой загрузке страницы.
