# Иллюстрации сценария «Малыш и лимонад»

Изображения извлечены из предоставленной автором презентации «Малыш и лимонад 3.4.pptx».
В каждом файле оставлен рисунок из соответствующего слайда; текст игровых
заданий и чисел хранится в сценарии и остаётся доступным для редактирования.

| Файл | Слайд презентации | Шаг игры |
|---|---:|---|
| `intro.png` | 4 | Введение |
| `d1.png`–`d6.png` | 8–13 | Дни 1–6 во дворе |
| `d7.png` | 16 | Переход в парк |
| `d8.png`, `d9.png` | 19, 20 | Кола в парке |
| `d11.png`–`d15.png` | 22, 24–28 | Лимонад в парке |
| `d14_order.png` | 27 | Вечерний заказ на понедельник |
| `d16_goal.png` | 30 | Прогноз до смартфона |

На обычный вторник (`d16`) повторно используется рисунок `d12.png`, как и
в презентации. На финальных итогах (`d17`) повторно используется `d6.png`.
